Push to GitHub

Uploads every image/video in your current content to its own file (never one giant blob), then commits your content as this file's new default.

Needs a GitHub Personal Access Token with write access to this one repo — it's kept only in this browser tab's session storage, never sent anywhere except directly to api.github.com.

Media is PUT directly to your Cloudflare Worker, which stores it in your R2 bucket and hands back a public URL — better suited to large files than GitHub's API. Your content (text/structure) still commits to GitHub as usual; only the media upload path changes. Requires a one-time Worker/R2 setup — ask for the setup steps if you haven't done this yet.
